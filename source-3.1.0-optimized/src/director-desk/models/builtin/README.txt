Built-in models:

- Props in this folder are generated from original project code
  in scripts/generate-built-in-models.mjs. No external meshes or
  textures are included for those files.

- Character models are third-party open assets used as-is:
  - ../valid-avatar-business.glb
    Valid Avatars GLB, AIAN_M_1_Busi (business outfit), from
    https://github.com/c-frame/valid-avatars-glb
    License: MIT (repository); retain upstream attribution when redistributing
  - character-male.glb
    three.js example "Xbot" (Mixamo), from
    https://github.com/mrdoob/three.js
    License: Mixamo character for use in applications / three.js MIT repo
  - character-soldier.glb
    three.js example "Soldier" (Mixamo), from
    https://github.com/mrdoob/three.js
  - character-cesium.glb
    Khronos glTF Sample Assets "CesiumMan"
    https://github.com/KhronosGroup/glTF-Sample-Assets
    License: Cesium glTF asset terms / CC-BY
