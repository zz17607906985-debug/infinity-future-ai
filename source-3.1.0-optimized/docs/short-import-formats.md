# 剧本与 Skill 导入

## 剧本

- 支持 .txt、.md、.markdown、.json、.docx，大小写扩展名均可。
- TXT/Markdown 支持 UTF-8、带 BOM 的 UTF-16 LE/BE；非 UTF-8 文本尝试 GB18030。乱码文件建议另存 UTF-8。
- DOCX 提取正文、段落与表格文字；不做图片 OCR，不保留 Word 排版。旧 .doc、PDF、扫描件、加密文档不支持，请先转换。
- 单个文件最多 25 MB，一次最多 200 个文件、总计 100 MB；合并正文最多 200 万字符。超过限制报错，不截断。
- 多选分集文件按文件名数字顺序合并，例如第2集在第10集前。建议使用 001、002 等编号，先检查预览列表。
- 预览只展示开头 4000 字符；确认导入的正文是完整内容。80 集导入能力不等于模型已完成80集资产审计。
- 替换导入会清空当前项目旧分镜、资产、声音方案和时间线，必须确认后才生效。需要保留旧成果时请使用另一个项目。
- 支持结构化 JSON：字符串、字符串数组，以及含 story/script/content/text/episodes/scenes 字段的对象。不是任意 JSON 文件。

JSON 示例：

```json
{"episodes":[{"episode":1,"title":"第一集","content":"这里放完整剧本文字，至少20个字符。"},{"episode":2,"scenes":[{"title":"车站","text":"这里放第二集场景的完整正文。"}]}]}
```

## Skill

- 三个独立槽位：剧本拆分、图片提示词、视频提示词；先选槽位再导入。
- 支持 .md、.txt、.zip，单文件最多 25 MB。ZIP 解压上限 64 MB、最多 2000 条目，入口必须是唯一 SKILL.md，可位于一层或多层目录中。
- 拒绝缺失/多个入口、重复路径、越界路径、CRC损坏、加密 ZIP、RAR、7Z。入口声明了另外两个已知 Skill 名称时提示切换槽位。
- 导入前展示目标槽位、入口、文件与资料数量、缺失引用警告；取消不切换当前 Skill。
- 原包保存在应用数据目录的 short-skill-packages，以内容摘要命名；图片及脚本等文件保留在原包中，不解压执行。版本元数据只保存入口与包标识。
- 运行时读取入口，按当前任务内容选择完整文本参考文件，参考正文上限约 10 万字符。模型可见完整目录和本次已展开资料；不是把整包所有资料都塞入每一次请求，也不声称执行了未展开资料。
- 包内 scripts 不自动执行，外部网址和包外引用不自动下载。存在缺失引用会在确认时提示。
- 替换后保留最多 12 个历史版本；恢复内置版本时仍保留自定义版本记录。不同项目使用同一组全局 Skill 槽位。

验证：npm test、npm run test:import-ui；可设置 FUTURE_AI_SKILL_TEST_DIR 对原始三个 ZIP 包进行本地解析验证。测试不会调用收费生成接口。
