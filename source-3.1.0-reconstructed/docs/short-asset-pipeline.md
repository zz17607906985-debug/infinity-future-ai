# 美术资产一键生产

导入或粘贴完整剧本后，直接进入“资产表 / 资产图”，不要求先创建分镜。

资产浏览使用固定排列的图片节点，默认每排 6 张，可选 3/4/5/6/8 张并记住偏好。图片区用滚轮上下浏览，图片延迟加载。支持分类以及名称、编号、别名搜索；输入“第1集”可按资产记录的集数精确筛选。点击图片打开大图与提示词编辑详情。搜索只影响浏览，不缩小上方或分类批量任务的生成范围。

- 一键生成美术提示词：无资产时先调用拆分 Skill 生成资产表，再以完整剧本、完整资产表、美术方向和当前资产调用图片提示词 Skill，由文本模型编译。仅调用文本模型。
- 一键完成并生图：先完成全部选中资产的提示词，再使用保存的提示词调用图片模型；已有图片跳过。
- 人物、场景、道具支持分别编译提示词或生成图片。每项支持查看正文依据、编辑提示词、Skill 重新编译、单张重新生图。
- 重编当前项会询问是否替换提示词；继续生图不重新编译来源未变化的提示词，保留手动修改。
- 失败或停止保留已完成结果，再次点击继续。停止不撤销已提交的供应商请求。
- 剧本或拆分 Skill 变更后须显式重新拆分；图片 Skill 或美术方向变更后会重新编译提示词。已有图片不自动覆盖。
- 提示词可导出为按类型、ID、名称排列的 TXT；结构化资产表及来源记录随项目保存。当前不是原 Skill 的 XLSX 多表/外部工具执行环境，Skill 引用的外部参考文件不会自动执行。
- 不截断到八项，也不在解析失败时伪造默认资产。长剧本超过模型上下文或返回不完整 JSON 时明确失败，不声称完成全量审计。

验证：`node scripts/test-short-asset-pipeline.js` 使用隔离模拟接口，不消耗真实额度。真实提示词质量和供应商调用效果需用用户实际剧本及配置验证。
