# ∞未来 AI 产品级开发计划（联网对标版）

> 制定日期：2026 年 9 月 5 日
> 适用版本：3.1.x；交付对象：AI 漫剧工作台与全局创作工具

## 总目标

把软件从“功能集合”升级为可持续生产的 AI 创作操作系统：用户能够导入内容、结构化创作、管理资产、生成画面、组织镜头、生成视频、审片交付，并在每一步看见状态、提示词、引用关系和下一步动作。

产品主流程：项目 → 剧本 → 资产 → 分镜 → 关键帧 → 视频/声音 → 质检 → 时间线/交付。所有模块共享同一项目状态、版本、引用关系、提示词记录和任务队列。

## P0 核心目标

### 1. 项目阶段导航
- [x] AI 漫剧工作台拆分为剧本、资产、视频三个主阶段。
- [x] 资产继续拆分人物、场景、道具三个独立区域。
- [x] 阶段切换时只显示当前阶段内容。
- [ ] 空状态改为明确的下一步引导，不再使用大面积无效空白。
- 验收：新项目打开后，用户能在 10 秒内理解当前阶段、完成状态和下一步动作。

### 2. 剧本输入与结构化
- [x] AI 生成剧本。
- [x] 导入 TXT、Markdown、JSON 剧本。
- [x] 导入新剧本时清理旧分镜、资产、质检、声音和时间线。
- [x] 增加基础剧本结构化分析：集数、场景、对白和角色统计。
- [x] 增加基础剧本结构化分析：集数、场景清单、对白和角色统计。
- [ ] 增加章节树、人物表、世界观资料和场景表。
- [ ] 增加 DOCX 导入并识别章节、角色、场景和对白。
- 验收：导入剧本后可编辑、审批，并一键进入资产和分镜拆分。

### 3. 资产生产闭环
- [x] 人物、场景、道具分区展示。
- [x] 三个板块可单独生成，也可全部批量生成。
- [x] 每张资产图显示提示词，支持编辑、保存和重新生成。
- [x] 生图链路固定为：用户提示词 → visual-prompt-engineer skill → 生图接口。
- [x] 支持资产锁定、版本和放入画布。
- [x] 增加身份、服装、材质、色彩和镜头引用字段。
- [x] 增加资产详情抽屉，展示生成记录、版本、状态和最终提示词。
- 验收：任何镜头都能追溯使用了哪些资产和版本。

### 4. Skill 与提示词追溯
- [x] 三类内置 skill 已安装登记。
- [x] 支持替换 skill 文件。
- [x] 资产表使用 script-to-asset-ledger。
- [x] 图片使用 visual-prompt-engineer。
- [x] 分镜和视频提示词使用 seedance2-director-prompts。
- [x] 视频实际生成请求强制经过 Seedance skill 并保存最终请求追溯。
- [x] 增加原始提示词、skill 处理结果、最终请求三段式预览，并支持从预览中保存修改后的提示词。
- [x] 增加 skill 版本、更新时间和恢复上一版本；替换时自动保存历史版本，可恢复内置版本。
- 验收：用户能看到每次生成实际发送的最终提示词和 skill 版本。

- 验收：用户可在镜头工作台完成生成、返工、排序和导出。

- [x] 声音方案、TTS、字幕、时间线和 MP4 导出能力已存在。
- [x] 音频溯源和文件哈希已有自动化验证。
- [ ] 增加视频、对白、旁白、音乐、音效、字幕多轨时间线。
- [ ] 增加片段拖拽、入点/出点、静音、替换和预览。
- [ ] 交付包增加项目、资产和 skill 版本索引。

### 7. 任务、费用与可靠性
- [x] 队列支持恢复、重试、暂停/继续、失败状态和多 Key 分配。

### 8. 全局 UI 与可访问性
- [x] 主要图标按钮已有中文标签和提示。

- [ ] 统一按钮层级、状态颜色、卡片、抽屉、表格和表单样式。
- [ ] 用列表、详情抽屉和预览替代无效空面板。
- [ ] 所有空状态提供主操作、次操作和帮助说明。
- [ ] 验证窄窗口和高缩放下不重叠、不截断。

## 实施顺序

1. 完成 P0 剧本、资产和 skill 追溯闭环。
2. 完成 P1 分镜、视频、声音和时间线联动。
3. 完成任务侧栏、费用确认、错误恢复和版本回溯。
4. 完成全局 UI 收敛、窄屏验收和真实供应商抽样。

## 交付门槛

- 自动化测试全部通过。
- 安装版构建成功，安装包与构建产物一致。
- 使用真实剧本完成人工验收：导入 → 资产 → 分镜 → 关键帧 → 视频 → 交付。
- 使用真实 API 验证图片、视频和声音链路。
- 未完成外部验收时，只标记“代码完成，外部验收待完成”，不宣称生产就绪。
