# 图片输出真实性

- 生成和编辑请求只发送所选尺寸，不静默改为低分辨率重试。供应商拒绝尺寸时报告错误。
- 成功返回的图片保留原 URL 和原始像素，不自动扩图、补边、裁切或插值缩放，包括旧配置 imageOutpaintPolicy=auto。
- 请求尺寸与返回尺寸分别记录。未匹配尺寸时保留成果并显示未达标，不冒充原生 4K。
- 保存后仍核验文件像素与接口原图一致，避免保存环节意外改变尺寸。
- 历史图片不覆盖；旧的插值放大结果明确标注非原生高分辨率。
- 尺寸匹配只说明像素宽高一致，不能保证供应商内部没有放大，也不保证模型遵循构图提示词。
- 自动化验证使用本地模拟图片，不调用真实付费生成接口。
